### 🚀 Featured Projects

#### [GD Analyzer — AI-Powered Group Discussion Analysis](https://github.com/DevshriDamle/gd-analyzer)
`Python` `Streamlit` `Faster-Whisper` `Pyannote` `Gemini API`
Transcribes and analyzes group discussions with speaker diarization and per-speaker HR-based performance scoring. Uses word-level timestamp matching between transcription and diarization for accurate speaker attribution, with automated Gemini-based feedback and downloadable PDF reports.

#### [CRUX — Problem-First Collaboration Platform](https://github.com/DevshriDamle/CRUX)
`Next.js` `FastAPI` `PostgreSQL` `pgvector` `Docker`
A full-stack platform connecting people through problems, skills, and expertise. Features an AI-powered matching engine using 384-dimensional embeddings and HNSW cosine similarity, JWT/OAuth authentication, and production-grade security — validated with 100+ backend tests and API contract checks across 100+ endpoints.

#### [VocalWings — AI-Powered Bird Species Identification](https://github.com/DevshriDamle/VocalWings)
`Python` `TensorFlow` `Keras` `CNN` `Librosa`
Identifies Indian bird species from audio recordings using a CNN trained on mel-spectrogram features, achieving 89.1% ± 4.5% accuracy. Includes live microphone recording, GPS-based GeoMapping, and confidence thresholding to filter unreliable predictions.
